# ☁️ TeleCloud

A beautiful, iCloud-style personal cloud drive that stores files in **your own Telegram account** — unlimited storage, no server, no database.

- Runs 100% in the browser and talks **directly to Telegram** (MTProto over WebSocket)
- Files live in a private channel named **TeleCloud Drive** in your account
- Folders, drag & drop (files and folders), upload/download progress, photo gallery, previews (images, video, audio, PDF, text), favorites, search, Recently Deleted (30 days), dark mode, mobile + "Add to Home Screen"
- Max file size: 2 GB (4 GB with Telegram Premium)

Built with GramJS + Vite. Deployed on GitHub Pages.
